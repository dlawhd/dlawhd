## 👨‍💻 About Me

- 요구사항을 **API와 데이터 모델로 구체화하는 과정**을 좋아합니다.
- 인증·인가, 예외 처리, 데이터 정합성처럼 **사용자에게 보이지 않는 안정성**을 중요하게 생각합니다.
- 문제가 발생하면 임시로 우회하기보다 **원인을 추적하고 구조적으로 개선**하려고 합니다.
- 기능 구현 이후에도 **테스트, 성능, 로그, 배포 환경**까지 확인하는 개발을 지향합니다.
