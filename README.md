## 🚀 Featured Project

### Memory Jar | 추억을 모으는 웹 서비스

소중한 사람들과 추억을 기록하고,<br>
약속한 날짜에 함께 열어보는 추억 저금통 서비스입니다.

**주요 기능**

- 자체 로그인 및 소셜 로그인
- 저금통 생성, 멤버 초대 및 권한 관리
- 추억 쪽지와 사진 및 영상 첨부
- WebSocket 기반 실시간 채팅 및 알림
- 예약된 날짜에 추억 공개 및 하루 한 장 뽑기

**사용 기술**

`Java 17` `Spring Boot` `React` `MariaDB` `AWS` `Docker`
