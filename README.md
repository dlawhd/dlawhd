## 🚀 Featured Project

### Memory Jar | 추억을 모으는 웹 서비스

**소중한 사람들과 추억을 기록하고, 약속한 날 다시 열어보는 서비스**

친구, 가족, 연인과 함께 추억 저금통을 만들고<br>
사진과 메시지를 모아 특별한 날에 다시 확인할 수 있습니다.

<br>

<!-- 프로젝트 기술 스택 -->

**Tech Stack**

`Java 17` `Spring Boot` `Spring Security` `React`

`MariaDB` `AWS EC2` `AWS S3` `Docker`

<br>

<!-- 실제 서비스의 주요 기능 -->

**주요 기능**

- 자체 로그인 및 Google·Naver·Kakao 소셜 로그인
- 저금통 생성, 초대 및 멤버별 권한 관리
- 추억 쪽지 작성과 사진·영상 첨부
- WebSocket 기반 실시간 채팅 및 알림
- 예약된 날짜에 추억 공개 및 하루 한 장 뽑기

<br>
